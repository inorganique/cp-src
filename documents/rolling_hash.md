# 滚动哈希

## 介绍

滚动哈希能逐个计算并存储序列每个前缀的哈希值,  
然后用它们 $O(1)$ 查询任一子数组 (即连续子序列) 的哈希值。

<br>

## 用法

### 构造

```cpp
rolling_hash hsh
```

只有默认构造。

<br>

### 追加整数

```cpp
void hsh.extend(ull x)
```

将 $x + 1$ 加入序列末尾, 取 $x+1$ 而不是 $x$ 是为了防止包含不同数量前导 $0$ 的子数组被算出相同哈希值。

**参数要求**

- $x\ne 2^{61}-2$

<br>

### 询问

```cpp
ull hsh.query(int l, int r)
```

查询 $[l,r]$ 的哈希值

**参数要求**

- $0\le l\le n$
- $-1\le r\lt n$
- $r-l+1\geq 0$ (可以令 $r=l-1$ 表示空区间)
