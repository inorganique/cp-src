# 二维树状数组

## 介绍

单点加, 矩阵和

<br>

## 用法

直接用代码简要介绍吧, 不多赘述:

```cpp
FenwickTree2D<ll> ft(h, w);  // h 行 w 列的矩阵
ft.add(x, y, v);             // 0 <= x < h, 0 <= y < w
ft.get(x, y);        // 左上为 (0, 0), 右下为 (x, y) 的子矩阵
ft.sum(x1, y1, x2, y2);      // 左上为 (x1, y1), 右下为 (x2, y2) 的子矩阵
// 可以令 (x2 - x1 + 1 = 0) 或 (y2 - y1 + 1 = 0) 表示空矩阵
```
